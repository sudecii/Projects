# 📊 Credit Scoring — ML Pipeline + FastAPI Service

## 💡 Описание проекта
Проект представляет собой полный ML-pipeline для прогнозирования вероятности дефолта клиента банка и прототип микросервиса скоринга на FastAPI.  
Выполнены этапы: анализ данных, фичеинжиниринг, обучение модели LightGBM, подбор оптимального порога выдачи кредита и интеграция модели в онлайн-сервис с Docker-упаковкой.

---

## 📂 Данные
Использован датасет соревнования **Fintech Credit Scoring (Kaggle)**:

- `application_info.csv` — признаки клиентов  
- `default_flg.csv` — факт дефолта  

Данные объединяются по полю `id`.

---

## 🧱 Feature Engineering
Добавлены инженерные признаки:

- `income_log = log1p(income)`
- `income_per_region_log = log1p(income / region_rating)`
- `age_per_rejcnt = age / (1 + appl_rej_cnt)`
- `app_month` — месяц подачи заявки
- `app_dayofweek` — день недели подачи заявки  

Создан единый список признаков `FEATURE_COLUMNS`, который используется и при обучении, и в продакшене.

---

## 🤖 Модель
Использована модель **LightGBM** внутри sklearn-Pipeline.  
Основная метрика качества:

### ⭐ ROC-AUC = **0.73**

---

## 🎯 Подбор порога
Метрика: **критерий Юдена (Youden’s J)**

- **Оптимальный порог выдачи кредита:** `0.1054`  
- Если `prob < threshold` → **approve**  
- Если `prob ≥ threshold` → **reject**
